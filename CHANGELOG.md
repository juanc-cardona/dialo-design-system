# Changelog

## 1.0.0 · 2026-10-28

Primera versión del sistema de diseño de Dialo, construida desde el brandbook v1.3.

- Tokens DTCG: paleta principal, escala del azul Dialo, neutrales, estados, tipografía Montserrat y Geist Mono, espaciado 4/8, radios, sombras y movimiento.
- Tema claro y superficie de marca (`data-surface="brand"`).
- 25 componentes CSS `.dl-*` y sus equivalentes React, incluidos los de conversación.
- 14 logos oficiales: maestros, producción (recorte transparente), encuadre con fondo, PNG y manifest.
- Favicon e iconos de app.
- Salidas para CSS, Tailwind v3/v4, JS, Figma (DTCG) y Claude Design.
- Sistema "Dialo" para Claude Design (artefacto Design System) generado desde el repositorio: 25 componentes con preview en vivo, temas Claro y Superficie de marca.
- CI: build, contraste WCAG (38 pares) y reglas de marca.
- Skill `dialo-brand`.
